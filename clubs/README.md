# Clubs

One folder per club other than The Nines (whose files are the site root). Each folder holds:

- `club.js`: the club's id (as in the `clubs` table), name, language (`en` or `fr`), tagline, footer and
  map address. See `js/club.js` for The Nines' version.
- `favicon.png` (512 × 512, also the logo on the pages), `favicon.ico` and `favicon-180.png`. Without
  them, The Nines' logo is used.

The folder name is the club's address: `clubs/lesronds/` is published at `site.thenines.club/lesronds/`.
No member data goes here: this repository is public.
